Dorakura-Kyoto GTK v1.0 Freeze
Stable usable build baseline
By GrandBIRDLizard

========================================
STATUS
========================================

This is the first stable usable GTK3 build of Dorakura-Kyoto.

Theme direction:
- Muted but strong
- Rounded-but-boxy
- TokyoNight + Dracula inspired
- Purple-forward identity without over-magenta drift
- Designed primarily around X11 i3 daily-driver usage

This freeze exists so future polish passes can be done safely
without losing the first stable working baseline.

========================================
WHAT IS WORKING
========================================

- GTK3 theme applies cleanly from ~/.local/share/themes/Dorakura-Kyoto
- Nemo main window themed and usable
- Nemo plugin/config panes no longer black
- Generic GTK dialog/popup surfaces mostly fixed
- GNOME Screenshot window surfaces themed
- Firefox and many GTK3 apps render acceptably under GTK_THEME
- Surface hierarchy now coherent:
  - chrome/header/footer = muted deep purple
  - sidebar = separate muted purple surface
  - content pane = darker inky main surface
  - menus/popups = neutral charcoal-violet
- Purple folder/icon direction established
